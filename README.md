# SEER

SEER 是一个以经典页游《赛尔号》为参考、可离线登舰的非官方三维同人复原项目。你将操控一名经典页游造型的小赛尔，从传送舱出发，沿走廊走进设备之间，也可以乘升降机前往其他甲板。

![精修版在传送舱内的实际画面](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.2.0/teleport-bay.jpg)

**直接游玩**　从 [GitHub Releases](https://github.com/lshxzhy/seer-starship-reconstruction/releases/latest) 下载 `seer-starship.html`，用支持 WebGL 的桌面浏览器打开。点一下画面，W/A/S/D 移动，Shift 快行，拖动环视，滚轮调整跟随距离，V 切换第一人称。“看正面”可以观察赛尔的面盘和双脚。触屏使用方向键和视角菜单。

**与角色交谈**　下载发布页的 `seer-starship-local.zip` 并解压，也可以直接使用本仓库。在装有 Python 3 和 Ollama、已安装 `qwen3.5:9b` 的电脑上，双击根目录的 **启动舰上通讯.cmd**。也可以在项目根目录执行以下命令。

```sh
python src/ai/server.py --open
```

浏览器打开本机登舰页。进入舱室，点 **舰上通讯**，选择联系人并输入问题。可远程联系罗杰等八位舰内具名角色和外部联系人麦哲伦；走到一名普通船员的四米范围内，也能按其 SE 编号交谈。每位联系人的会话在当前页面内单独保留，刷新即清空。关掉自己启动的服务窗口即可结束本次服务。所有角色共用本地模型，舰上通讯默认关闭思考并流式显示正文。模型和私聊留在本机。[舰上组织、角色与资料出处](docs/舰上组织与角色.md)

默认“精细”画质保留舱内反射、甲板接缝和屏幕空间接触遮蔽。“流畅”降低像素预算并直接绘制场景。想观察机体细节，可点“看正面”并向前滚动鼠标滚轮；在传送舱、瞭望舱或动力室点“近看设备”，会以第一人称站到机器旁，仍可自由走动。浏览器支持时可切换全屏。

**从源码构建**　安装 Python 3.8 或更新版本，在仓库根目录运行：

```sh
python work/assemble-seer.py
```

直接打开生成的 `outputs/seer-starship.html`。Three.js r128 随源码分发，构建使用 Python 标准库，运行时从本文件读取模型和渲染库。

## 舰上有哪些空间

手册标注的船长室、实验室、资料室、瞭望舱、瞭望露台、荣誉大厅、传送舱、机械室、教官办公室、发明室和动力室均可进入。不同舱室的图证年代与精修进度见[资料索引](docs/SOURCES.md)。

手册外廓为 530 × 370 × 450 米。可游玩的舰体采用 1.5 倍扩建尺寸，设四层驻舱、十六个分区和 12,000 个可定位的充能位。名册包括玩家和 11,999 名船员。船员按编号、路线与轮班时钟确定位置；当前甲板在玩家附近 42 米内最多绘制 112 名 NPC。

首版重点是基础赛尔机体、底层走廊、传送舱、动力室和瞭望舱。截图能确认设备的正面和相对遮挡；背板、支撑、米制尺寸、跨层接驳和承载万人所需的设施均有项目设计成分。
