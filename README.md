# SEER

SEER 是经典页游《赛尔号》的三维同人项目。你可以操控小赛尔在舰内走动，携带超能 NoNo 和精灵搭乘实体升降舱、驾驶登陆艇，在帕诺星系的克洛斯星和海洋星探索。

**直接游玩**　下载 `seer-starship.html`，用支持 WebGL 的浏览器打开。点一下三维画面，按 **WASD** 移动，按住 **Shift** 快行，拖动环视，按 **V** 切换视角。触屏可以使用方向键。[下载最新离线版或源码运行包](https://github.com/lshxzhy/seer-starship-reconstruction/releases/latest)

**本版的探索尺度。** 克洛斯星半径 48 公里，海洋星半径 41 公里。经典步行区仍按米布置，克洛斯草原到三处外围地标现约 3.2～4.9 公里。野外与随行精灵以图鉴身高的 1.65 倍显示，草原矿簇、钓具、摇树和地心机关放大 40%。按 **M** 可到草原近看皮皮和矿簇，或到海洋星深水区看利牙鱼和蓝色口腔护理站。[场景与角色图证](docs/SOURCES.md)

**拜访舰员。** 在舰图选舱室能看到值班姓名。走到工位四米内，点人物、点「拜访」或按 **E** 打开资料卡。船长室有罗杰，实验室有派特，机械室有茜茜，动力室有苏克。雷蒙、肖恩、爱丽丝和克罗也各在其舱。本机通讯版可从资料卡直接联系本人。[八名角色及原作图证](docs/舰上组织与角色.md)

## 在舰上能做什么

- **逛舱室、乘升降舱。** 十一处经典舱室、公共走廊和四层驻舱在同一艘扩建舰上。按 **M** 选舱室或升降站，可看路线或直接传送。在层门外呼梯，开门后带伙伴进厢，用轿内实体甲板键选层。去腹舱动力室需在底层换乘检修线。另有七处工程区显示在分层总图中，仍待开放。[舰内地图](docs/地图系统图证.md) · [升降系统](docs/舰内升降系统.md)
- **交付自己采的矿样。** 到机械室左侧工位领钻，按 **B** 装备钻头，再采训练矿样。沿金色箭头，经检修升降站抵达动力室，走到中央主机前的矿物投入口，选数量并确认。三份矿样都能分批交付，每份 20 赛尔豆，收据可回看。[背包与采样](docs/背包系统图证.md) · [兑换柜台与原版依据](docs/动力室物资兑换图证.md)
- **与伙伴同行。** 在终端可以让面屏显示笑眼，招呼超能 NoNo。奥飞滑翔翼供单人在甲板低空驾驶，按 **F** 取出、登乘或着陆，空格和 **C** 控制高度。舰上名册含玩家和 11,999 名船员，四层十六区共 12,000 个充能位；玩家附近 42 米内最多绘制 112 名船员。[赛尔面盘](docs/面盘表情图证.md) · [超能 NoNo](docs/超能NoNo图证.md) · [滑翔翼](docs/单人飞行器图证.md)

## 驾驶 L-01 去两颗星球

从底层传送舱的编号机位按 **E**，乘廊车到舷侧泊位，沿尾坡走进艇首，再按 **E** 进入驾驶席。打开「航线」选择目的地，可自动飞往，也可设为手动航点。停稳后点「离席下船」并走下尾坡。返航时登上原艇，选「赛尔号 · 原泊位」。艇上的航线、接管和视角实体键也可操作。奥飞在开阔甲板的普通／加力上限为 15／24 米每秒。L-01 在开阔近星高空可加力至 8 公里每秒，远离天体的星际段可加力至 260 公里每秒。舱门、障碍物、地表和泊位附近都会按净空与制动距离降速。[机位接口](docs/舰内传送舱接口.md) · [登陆艇驾驶说明](docs/载人登陆艇.md)

- **克洛斯星。** 经典草原、沼泽、林间等八区可以步行连通，山脊、河口和林台也可驾驶登陆艇抵达。草原可观察皮皮转向和短跳，地心有解开四处机关后出现的石晶晶。[星图、地貌与版本](docs/克洛斯星图证.md) · [野外精灵与机关](docs/克洛斯星精灵图鉴.md)
- **海洋星。** 选浅海登陆平台，沿黄栏斜坡下水，经过浅水区、深水区、钢牙鲨所在的海底，可继续步行到后期的深海禁地。星系轨道图、两颗球体和 L-01 共用坐标与模拟时钟。按 **M** 直接传送的是人员，停放的登陆艇可在地图上定位。[帕诺轨道与海洋星](docs/帕诺轨道与海洋星.md)

## 收服、培养和挑战精灵

底栏「精灵」可从布布种子、伊优、小火猴中领取初始伙伴。在地表点「观察」后可拖动绕精灵环视，滚轮调整观察距离。走近野生精灵后点「接触」发起回合对战；压低体力后可投胶囊。最多六只精灵在队，其他可存仓。可调整首发和随行个体、学习技能、升级进化。实验室开放克洛斯星收集计划和黄金布布的融合孵化路线。[精灵规则与资料来源](docs/精灵系统.md)

- **SPT 首领。** 在「精灵 → SPT 首领」选择任务。克洛斯星林间的蘑菇怪需先到实验室领装备，连续照射三次破开护膜；首胜得 1 级小蘑菇和 3,000 点可分配经验。海洋星海底的钢牙鲨为 25 级、200 体力，首胜得黑晶矿。深水区的利牙鱼可捕捉，20 级进化为钢牙鲨。[蘑菇怪](docs/克洛斯星精灵图鉴.md) · [钢牙鲨](docs/帕诺轨道与海洋星.md)
- **克洛斯湿地捕猎场。** 向管理员报名，每场 15 分钟、20 枚专用胶囊。37 种场内精灵可以通过地面接触、步行、垂钓、摇树或集晶遇见。本项目免费入场。[当期名单与出现方式](docs/克洛斯星精灵图鉴.md)
- **图鉴与存档。** 完整离线版和本机版可查 4,932 个条目，现有 105 个形态可获得或培养，另有 4 个历史观察形态。图鉴标明本期来源。要把队伍从离线版带到本机版，用「精灵 → 仓库 → 精灵存档」导出，再在另一入口导入。[还原范围](docs/精灵系统.md)

## 本机通讯与源码构建

从发布页解压 `seer-starship-local.zip`，或使用本仓库。已安装 Python 3、Ollama 和 `qwen3.5:9b` 时，双击「启动舰上通讯.cmd」，也可以在项目根运行：

```sh
python src/ai/server.py --open
```

在「终端 → 舰上通讯」联系具名角色，或走到普通船员身旁按编号交谈。野外、队伍与图鉴各有精灵交流入口。本机模型按角色和现场状态生成中文回应，默认关闭思考。单文件版可离线完成探索、对战和存档。[角色通讯与名册](docs/舰上组织与角色.md)

只构建离线游戏时，在项目根运行 `python work/assemble-seer.py`，然后打开 `outputs/seer-starship.html`。Three.js r128 随仓库提供。画质固定为精细；终端内保留全舰外观、纵剖、分层、角色正面与设备近看视角。
