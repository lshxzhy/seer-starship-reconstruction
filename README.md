# SEER

SEER 是一个以经典页游《赛尔号》为参考的离线三维同人项目。你能带着超能 NoNo 走遍赛尔号，从舰内传送舱前往帕诺星系，在克洛斯星草原寻找皮皮。

![小赛尔与超能 NoNo 驾驶 L-01 登陆艇驶离赛尔号舷侧泊位](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.9.0/departure.jpg)

**直接游玩**　下载发布页的 `seer-starship.html`，用支持 WebGL 的浏览器打开，点一下舱内画面，把键盘交给小赛尔。[下载最新版](https://github.com/lshxzhy/seer-starship-reconstruction/releases/latest)

## 从舰内传送舱出发

在底层传送舱走进编号机位的地面亮框，按 **E** 乘廊车到舷侧泊位。也可以在本舱终端选择「前往传送位」找到入口。下廊车后按 **W** 沿登陆艇尾坡走进客舱，到艇首按 **E** 操作驾驶席，点「自动飞往草原南坪」即可出发。选「手动离泊」可自己驾驶，按 **V** 可在舷窗与艇外视角之间切换。地面停稳后点「离席下船」，从尾坡步行下船，去草原找皮皮。返程时从原艇尾坡登船，在驾驶席选「自动飞往赛尔号泊位」，对接后经尾坡、廊车回到出发机位。[登陆艇操作](docs/载人登陆艇.md) · [舰内传送舱接口](docs/舰内传送舱接口.md)

克洛斯星的模型半径为 **480 公里**，赤道周长约 3016 公里。经典草原、沼泽、林间等八处地点仍可步行串联。驾驶登陆艇可到约 16 公里外的蓝脊山鞍部、20 公里外的金河口高岸和 25 公里外的绯叶林台，也可在其他平缓、干燥且有净空的地面停放。外围三处地形、登陆艇与泊位为本项目的飞行设计。[原作地图与版本依据](docs/克洛斯星图证.md)

从轨道可以看到经典帕诺星图上的金色斜环和灰青、橄榄、灰紫宽带。落地后，草原的珊瑚红土与蓝草岩台在橙红天光下相接，沿路走进沼泽会见到赭黄泥池；地心的青蓝池水由玫紫岸草环绕。[2016 年星图与草原实景](https://news.4399.com/news/seerwenda/610708.html) · [本版轨道](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.8.1/klose-orbit.jpg) · [本版草原](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.8.1/klose-grassland.jpg)

## 舰上操作

- **舰内地图（M）**　在画面底栏打开地图，选择甲板，再点舱室查看步行路线和升降站换乘提示。要马上抵达可选“传送至此”。舱室位置取自本艘扩建舰。[地图图证](docs/地图系统图证.md)
- **背包（B）**　打开储存箱可查看随身舰图、取出或收回自己的奥飞滑翔翼。去机械室的采样工位领取挖矿钻头，在背包点“装备钻头”，再靠近工位选“钻取训练矿样”。每取走一块，背包就多一块，这里共有三块舰内训练样品。原版资料中的黄晶矿采自星球。[背包图证](docs/背包系统图证.md)
- **步行参观**　按 W 前进、S 后退，A/D 左右平移。步速为 3.6 米/秒，按住 Shift 快行可达 6.8 米/秒。用鼠标或触屏点画面上的方向键可走一小步，按住可连续走。拖动环视，滚轮调整跟随距离，V 切换第一人称。
- **看表情和伙伴**　打开画面内的终端，选择微笑或招呼身旁的超能 NoNo。赛尔的屏幕会显示两道拱起的笑眼，白壳青翼的伙伴会转向你、眨眼致意。[面盘图证](docs/面盘表情图证.md) · [超能 NoNo 图证](docs/超能NoNo图证.md)
- **驾驶奥飞滑翔翼**　传送舱内停有一台滑翔翼。走近按 F 登乘；离它较远时，在开阔处按 F 可先取到身旁，再按 F 登乘。W/A/S/D 驾驶，巡航上限 8.2 米/秒，按住 Shift 加速至 11.5 米/秒。空格升高、C 降低，再按 F 着陆下机。触屏可用滑翔翼按钮和“升高”“降低”。超能 NoNo 随机身升降，着陆后滑翔翼留在甲板上。[滑翔翼实机图证](docs/单人飞行器图证.md)

## 乘升降舱去其他甲板

塔桥主升降机沿垂直导轨连接底层机务区、四层驻舱、中心层、上层和塔顶船长室。前往腹舱动力室需在底层换乘检修升降机。这条线路沿腹舱颈部的斜轨运行，全程约 147 米，轿厢地板保持水平。车在另一层时，可以点门框上的“呼梯”。开门后走进去，等伙伴入厢，再点轿厢门旁的实体甲板键或画面中的选层器。乘车时可在厢内走到窗边，拖动环视，按 V 可切换视角。矿样、工具仍在当前玩家的背包里。[轿厢、导轨和运行参数](docs/舰内升降系统.md)

## 跟着路标送矿样

在机械室左侧工位领钻并采样。采下第一份后，甲板就会出现**金色箭头**。如果已经在旧版采过，打开背包选中训练矿样，点“跟随路标交付”即可。空手也能从终端打开去矿架的引导。

1. 在机械室沿箭头走向出舱门，经过支廊，到主廊转向动力舱检修升降站。
2. 在检修站候梯。轿厢在别层时先点“呼叫轿厢”；车到开门后带超能 NoNo 走进厢内，在“轿厢选层”选择“腹舱动力区”。透过车窗可以看见斜轨和井壁灯掠过。到站停稳、层门与轿门完全打开后，走出轿厢，按动力室舱门标牌进舱。
3. 绕过前方的小游戏操作台，走到中央主机前，点小门上的“矿物投入口”或画面里的“能源兑换台”。选择本次交付数量并确认。训练样品可以分批交付，每份奖励 20 赛尔豆。台面和终端可重看回执，已交出的样品会从背包扣除。

经典动力室的场景文件把矿物兑换入口放在中央主机前；原面板有增减数量、单价、合计和兑换按钮。原作黄晶矿当时列价 20 赛尔豆。舰内训练用矿、实体检修路线和签收回执由本项目设计。[原版动力室图证](docs/动力室物资兑换图证.md)

**与角色交谈**　下载发布页的 `seer-starship-local.zip` 并解压，也可以直接使用本仓库。在装有 Python 3 和 Ollama、已安装 `qwen3.5:9b` 的电脑上，双击根目录的 **启动舰上通讯.cmd**。也可以在项目根目录执行以下命令。

```sh
python src/ai/server.py --open
```

浏览器打开本机登舰页。进入舱室，打开 **终端 → 舰上通讯**，选择联系人并输入问题。可远程联系罗杰等八位舰内具名角色和外部联系人麦哲伦；走到一名普通船员的四米范围内，也能按其 SE 编号交谈。每位联系人的会话在当前页面内单独保留，刷新即清空。关掉自己启动的服务窗口即可结束本次服务。所有角色共用本地模型，舰上通讯默认关闭思考并流式显示正文。模型和私聊留在本机。[舰上组织、角色与资料出处](docs/舰上组织与角色.md)

画质固定为“精细”，保留舱内反射、甲板接缝和屏幕空间接触遮蔽。从终端点“看正面”，向前滚动鼠标滚轮可近看赛尔。在传送舱、瞭望舱或动力室点“近看设备”，会以第一人称站到机器旁，仍可自由走动。终端也可切换舰体外观、纵剖和分层，或进入全屏。

**从源码构建**　安装 Python 3.8 或更新版本，在仓库根目录运行：

```sh
python work/assemble-seer.py
```

直接打开生成的 `outputs/seer-starship.html`。Three.js r128 随源码分发，构建使用 Python 标准库，运行时从本文件读取模型和渲染库。

## 舰上有哪些空间

手册标注的十一处舱室和四层驻舱都安装在同一艘扩建舰上。同层舱门经支廊接入主廊。**从机械室去传送舱**，先转身找到进来时的舱门，出门沿支廊直行，穿过主廊后，正对面的支廊就通往传送舱。两道舱门相距 59 米。

跨层时走进升降站，在出现的换层入口选择停靠层。塔桥主升降机连接底层机务区、四层驻舱、中心科研区、顶层观测区和塔顶船长室。前往腹舱动力室须在底层换乘动力舱检修升降机。也可以从地图选择已开放的舱室直接前往。另有七处工程区仍是总图上的规划空间，例如物资储备舱和导航值班区。游戏画面出处与已制作范围见[资料索引](docs/SOURCES.md)。

手册外廓为 530 × 370 × 450 米。可游玩的舰体采用 1.5 倍扩建尺寸，设四层驻舱、十六个分区和 12,000 个可定位的充能位。名册包括玩家和 11,999 名船员。船员按编号、路线与轮班时钟确定位置；当前甲板在玩家附近 42 米内最多绘制 112 名 NPC。

首版重点是基础赛尔机体、底层走廊、传送舱、动力室和瞭望舱。截图能确认设备的正面和相对遮挡。背板、支撑、米制尺寸、跨层接驳和承载万人所需的设施均有项目设计成分。[v0.2.0 传送舱实景](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.2.0/teleport-bay.jpg)
