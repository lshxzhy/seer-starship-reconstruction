# SEER

SEER 是页游《赛尔号》的三维同人项目。你可以操控小赛尔在舰内走动，携带超能 NoNo 和精灵搭乘实体升降舱、驾驶登陆艇，在帕诺星系探索四颗行星，也可以登上拜伦号，重访《穿越黑暗之门》的吞舰现场。

**直接游玩**　下载 `seer-starship.html`，用支持 WebGL 的浏览器打开。点一下三维画面，按 **WASD** 移动，按住 **Shift** 快行，拖动环视，按 **V** 切换视角。触屏可以使用方向键。[下载最新离线版或源码运行包](https://github.com/lshxzhy/seer-starship-reconstruction/releases/latest)

本分支接续步行跳跃、常用装备、星球采集和模型修正，并整合小星球、场景覆盖、自动观景与版本更新入口。最新共同源码位于 `codex/desktop-development-20261112`；此前 release 下载不代表已经包含本轮修改。实现范围、交付及节点采用分别见[开发交接](docs/HANDOFF.md)。

**看拜伦号被引力撕裂。** 从舰内按 **M → 拜伦号 → 吞舰现场 · 逃生舰 → 传送到此**。停在舷窗前，能看到暗青舰壳的几个破口不断剥落碎片，残骸翻转、碎开，最后汇入红白核心。可点「举起观测镜」追踪其中一束，或驾驶 L-01 绕近断面。巨影高约 1,200 米，约有 7.5 个舰长。[原作星图、构图与操作](docs/拜伦号与原始黑洞.md)

**从当前位置出发。** 舰内和行星步行时按 **M** 打开导航图。选「步行引导」后可跟着路标走，画面上的「取消路线 · Esc」随时停止引导；地图中的「取消当前路线」不受正在查看的地点影响。关图后键盘焦点返回游戏。也可在同一张图切换区域，直接传到其他星球或舰内舱室。在 L-01 上按 M 打开艇载航线。[地图操作](docs/地图系统图证.md)

**在双子星看伴星。** 阿尔法地表只显示贝塔，贝塔地表只显示阿尔法；方向和高度随实际位置与轨道变化，低空保留原作大星盘的景观放大。按 **M → 望向伴星** 朝当前伴星方向看，位于地平线以下或被洞顶挡住时不可观测。[双星天空与地貌图证](docs/帕诺双子星.md)

**本版的探索尺度。** 克洛斯、海洋、阿尔法、贝塔的球体半径分别为 900、600、800、850 米，经典场景保留既有米制尺寸和 1.7 倍场景尺度，独立区域分布到球面。普通精灵、人物和登陆艇保持米制体型。旧航程按稳定地点与局部距离迁移，背包、精灵个体和奖励记录沿用；详细地貌覆盖及实际查看范围见[开发交接](docs/HANDOFF.md)。瞭望舱和瞭望露台使用对应真实内舱的贯通玻璃窗。

**拜访舰员。** 在舰图选舱室能看到值班姓名。走到工位四米内，点人物、点「拜访」或按 **E** 打开资料卡。船长室有罗杰，实验室有派特，机械室有茜茜，动力室有苏克。雷蒙、肖恩、爱丽丝和克罗也各在其舱。本机通讯版可从资料卡直接联系本人。[八名角色及原作图证](docs/舰上组织与角色.md)

## 在舰上能做什么

十一舱的设备、四颗行星的 21 个经典地点、舰艇和精灵近景的本期改动均有逐项记录。[场景与模型精修清单](docs/场景与模型精修.md)

- **逛舱室、乘升降舱。** 十一处经典舱室、公共走廊和四层驻舱在同一艘扩建舰上。按 **M** 选舱室或升降站，可看路线或直接传送。在层门外呼梯，开门后带伙伴进厢，用轿内实体甲板键选层。去腹舱动力室需在底层换乘检修线。另有七处工程区显示在分层总图中，仍待开放。[舰内地图](docs/地图系统图证.md) · [升降系统](docs/舰内升降系统.md)
- **交付自己采的矿样。** 在机械室矿架旁，依次按 **E** 领取钻头、装备、钻取训练矿样。也可以按 **B** 管理装备。沿金色箭头经检修升降站抵达动力室，走到中央主机的投入口，按 **E** 打开兑换台，选数量并确认。三份矿样可分批交付，每份 20 赛尔豆，收据可回看。[背包与采样](docs/背包系统图证.md) · [兑换柜台与原版依据](docs/动力室物资兑换图证.md)
- **步行跳跃（本轮新增）。** 在母舰、行星和拜伦号步行时，点回三维画面后按 **空格** 起跳，WASD 可以同时移动。按住空格不会连续跳跃，头顶过低时无法起跳。落地后再采集、登艇、乘滑翔翼或选择升降层；驾驶载具时，空格仍用于升高。跳跃沿用原有可走范围，不会绕过场景障碍。
- **穿装备到星球作业（本轮新增）。** 机械室工位一次配发钻头、气体收集器和潜水套装，在 **B → 背包** 中穿戴；喷火器仍从实验室领取。钻头可采克洛斯草原和海洋深水区的黄晶矿，收集器可采海洋浅水区的甲烷。靠近标记并面向它按 **E**，站稳约两秒完成采集，移动或 **Esc** 可取消。每个采集点在同一存档中只发一份标本。到动力室投入口前，在背包选「星球采集物 → 交付采集物」，一次交出当前未售物资；黄晶矿每份 20 豆，甲烷每份 100 豆。潜水装恢复正常步速，第一／第三人称水下照明均已接入本轮源码；喷火器用于林间蘑菇怪护膜。[领取、穿戴与采集规则](docs/背包系统图证.md)
- **与伙伴同行。** 舰内「终端 → 赛尔操控」和行星「地表图」都可切换小赛尔的八种面屏表情，选中后可从正面看到发光点阵。在终端还能招呼超能 NoNo。奥飞滑翔翼供单人在甲板低空驾驶，按 **F** 取出、登乘或着陆，空格和 **C** 控制高度。舰上名册含玩家和 11,999 名船员，四层十六区共 12,000 个充能位，玩家附近 42 米内最多绘制 112 名船员。[赛尔面盘](docs/面盘表情图证.md) · [超能 NoNo](docs/超能NoNo图证.md) · [滑翔翼](docs/单人飞行器图证.md)

## 驾驶 L-01 去四颗星球和拜伦号

底层传送舱的 **01、02 号**预设克洛斯星草原南坪，**03、04 号**预设海洋星浅海登陆平台。01、02 号可在终端的「目的地」切换双子阿尔法星，03、04 号可切换双子贝塔星。按标牌走进亮框，或在本舱的「终端 → 登乘机位」选定编号后点「前往所选机位」。在亮框内按 **E**，乘廊车到舷侧泊位，沿尾坡走进艇首，再按 **E** 进入驾驶席。打开「航线」选择目的地，可自动飞往，也可设为手动航点。驾驶区的自动／手动切换共用一个按钮，也可按 **P**；自动期间拖动、方向键与 W/A/S/D 只调整视线，按 P 可明确手动接管；停稳后按 **J** 或点「离席 · J」，再向艇尾步行下船，实际查看范围见开发交接。返航时登上原艇，选「赛尔号 · 原泊位」。艇上的航线、接管和视角实体键也可操作。奥飞在开阔甲板的普通／加力上限为 15／24 米每秒。L-01 自动近景航速约 12～28 米每秒，星际自动上限 800 米每秒；手动航速随净空与持续加力增加。舱门、障碍物、地表和泊位附近都会按净空与制动距离降速。[机位接口](docs/舰内传送舱接口.md) · [登陆艇驾驶说明](docs/载人登陆艇.md)

- **克洛斯星。** 经典草原、沼泽、林间等八区可以步行连通，山脊、河口和林台也可驾驶登陆艇抵达。草原可观察皮皮转向和短跳，地心有解开四处机关后出现的石晶晶。[星图、地貌与版本](docs/克洛斯星图证.md) · [野外精灵与机关](docs/克洛斯星精灵图鉴.md)
- **海洋星。** 选浅海登陆平台，沿黄栏斜坡下水，经过浅水区、深水区、钢牙鲨所在的海底，可继续步行到后期的深海禁地。星系轨道图、四颗球体和 L-01 共用坐标与模拟时钟。按 **M** 直接传送的是人员，停放的登陆艇可在地图上定位。[帕诺轨道与海洋星](docs/帕诺轨道与海洋星.md)

- **双子阿尔法星。** 从碧色温泉群进入紫根岩地，抵达海盗能源塔；从另一条路可进复色后的黑白森林。走近能源站右翼的传送盘，按 **E** 可以前往贝塔星荒原。
- **双子贝塔星。** 从巨型六钻掘进机所在的机坪，到电能石裂谷和透明勘察站；要塞废墟、海盗训练场与精灵召唤场也可游览。在两星地表朝向伴星的一侧可以用 **18× 望远镜** 追踪它的真实方向。[双子星九处场景、门表与原作图证](docs/帕诺双子星.md)
- **拜伦号。** 在 04 号机位另选「拜伦号」，可驾 L-01 到左舷靠泊甲板。走下尾坡，经甲板、神秘空间到达精灵舱。人员地图上的逃生舰与主舰各自独立。[靠泊与舱内路线](docs/拜伦号与原始黑洞.md)

## 收服、培养和挑战精灵

底栏「精灵」可从布布种子、伊优、小火猴中领取初始伙伴。在地表点野生精灵或「观察」进入近景，拖动环视，滚轮调距离，**Esc** 返回。按 **E** 或点「接触」打开该个体的资料，选「进入对战」或「挑战首领」才开始战斗。可捕的普通精灵压低体力后可投胶囊，首领及原数据捕获率为零的形态不能直接捕捉。最多六只精灵在队，其他可存仓。实验室开放克洛斯星收集计划和黄金布布的融合孵化路线。[精灵规则与资料来源](docs/精灵系统.md)

本轮源码已接入双子星 15 种现场物种的对战，并将普通现场与随行精灵比上一版放大 25%、四位可挑战 Boss 放大至上一版的 2.5 倍；图鉴原始身高和战斗数值保持原数据。新增功能的统一构建、实际加载和查看范围由[开发交接](docs/HANDOFF.md#2026-11-12-精灵放大双星对战与养成整合源码交付)记录。

- **SPT 首领。** 在「精灵 → SPT 首领」选择任务。克洛斯星林间的蘑菇怪需先到实验室领装备，连续照射三次破开护膜；首胜得 1 级小蘑菇和 3,000 点可分配经验。海洋星海底的钢牙鲨为 25 级、200 体力，首胜得黑晶矿。本轮新增阿尔法岩地纳多雷（50 级、1,200 体力）与贝塔荒原雷纳多（70 级、1,600 体力），首胜分别得 1 级纳格与 8,000 经验、1 级雷格与 12,000 经验；队伍满员则幼体入仓，首胜不重复发放。双星首领采用项目游览规则，未复刻全部原作谜题和免疫机制。[蘑菇怪](docs/克洛斯星精灵图鉴.md) · [钢牙鲨](docs/帕诺轨道与海洋星.md) · [双星挑战](docs/帕诺双子星.md)
- **快捷养成。** 队伍和仓库共用个体面板，可预览升 1 级、升 5 级、练到下一进化或投入可用经验的费用；满级只扣实际所需，余量留在余额。每场胜利另积累一次可分配经验。推荐配招先预览再采用，使用已学或进化继承的合法技能，保留已消耗 PP。[培养与技能规则](docs/精灵系统.md)
- **克洛斯湿地捕猎场。** 向管理员报名，每场 15 分钟、20 枚专用胶囊。37 种场内精灵可以通过地面接触、步行、垂钓、摇树或集晶遇见。本项目免费入场。[当期名单与出现方式](docs/克洛斯星精灵图鉴.md)
- **图鉴与存档。** 完整离线版和本机版可查 4,932 个条目，本轮培养名册由 110 扩至 135 个形态，另有 4 个历史观察形态。新增十个家族形态使用已标注的简化造型，仍待原立绘精修；部分条件进化和其他三维造型仍待接入。要把队伍从离线版带到本机版，用「精灵 → 仓库 → 精灵存档」导出，再在同版的另一入口导入。[还原范围](docs/精灵系统.md)

## 本机通讯与源码构建

从发布页解压 `seer-starship-local.zip`，或使用本仓库。已安装 Python 3、Ollama 和 `qwen3.5:9b` 时，双击「启动舰上通讯.cmd」，也可以在项目根运行：

```sh
python src/ai/server.py --open
```

源码版启动时会读取登记的 GitHub 共同分支，仅对干净且可快进的同名分支更新；本地独有修改、分叉和玩家存档保留。开始接续开发或收到固定提交通知时，运行 `python src/ai/server.py --check-updates` 只检查更新，不构建或打开游戏。网络失败会说明当前本地版本与“最新未确认”；不以启动成功代替最新版本确认。预构建包使用包内 HTML，不冒充完整源码库。[共同版本规则](docs/HANDOFF.md#2026-11-12-小星球整合与共同版本入口)

在「终端 → 舰上通讯」联系具名角色，或走到普通船员身旁按编号交谈。野外、队伍与图鉴各有精灵交流入口。本机模型按角色和现场状态生成中文回应，默认关闭思考。单文件版可离线完成探索、对战和存档。[角色通讯与名册](docs/舰上组织与角色.md)

只构建离线游戏时，在项目根运行 `python work/assemble-seer.py`，然后打开 `outputs/seer-starship.html`。Three.js r128 随仓库提供。画质固定为精细；终端内保留全舰外观、纵剖、分层、角色正面与设备近看视角。
