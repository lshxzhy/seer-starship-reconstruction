## v0.14 工位、设施与移动

- **舰员。** 八位常驻舰员有不同的头部轮廓、面屏和岗位装备。模型参照淘米公开的具名 NPC 立绘，服装背面和使用工位时的走停按可游玩三维空间补全。[八张原作立绘及对应人物](舰上组织与角色.md)
- **舱室。** 对照经典画面调整资料室的圆形 S 地徽、露台扭蛋机的金喙和蓝冠、教官办公室斜台的分段包边、荣誉大厅 SENIOR 板旁的金色轴环。显微镜的物镜、工具夹爪、设备背面、升降门槛及驻舱充能母排是三维工程细节。[舰内录像与十一舱来源](#游戏录像与进服记录)
- **两颗行星。** 克洛斯星按各区地貌补树冠、叶脉、矿晶与菌褶；海洋星补沉积纹、晶带、珊瑚花萼和近景砂纹。湿地圆池和神宠之境地面嵌石分别对应 550 与 943 号场景。[克洛斯图证](克洛斯星图证.md) · [海洋四区](帕诺轨道与海洋星.md)
- **载具。** 奥飞的外形参考 2012 年领取与乘用画面；两类飞行器的速度上限、制动距离、尾坡液压和近星驾驶手感是本项目设定。[同期奥飞画面](https://news.4399.com/gonglue/seer/saiergonglue/201212-20-223645.html)
