# 造型与场景资料

经典页游是基础角色与十一舱的造型基线。每条记录标明资料能支持的观察，时间优先使用可复查的原页面日期。三维模型由代码重建。原站图片和录影片段未随仓库发布。

## 角色

- 2010 年创建人物画面给出正面全身和生产线侧面。圆壳下方直接是底箍、双杆和两只鞋；顶部按钮、外凸面盘和侧盖也可辨认。[创建人物指南](https://news.4399.com/seer/xinshouzhinan/201005-28-69808.html)
- 2014 年“小赛尔”对白像提供四分之三视角，可定位面框、侧盖和白色眼区。项目设定全高 1.70 米，背壳与伸缩关节是当前工程解释。[新手指南](https://news.7k7k.com/content/20140609/653372.html)

## 舰体与三个层区

手册第 6 页载外廓参数，第 7 页说明三大层区、走廊和电梯，第 8 页标注十一处空间。动力室随手册位于后下悬舱；纸本图鉴给出的引线另指主船体下部。扩建后尺寸、九个停靠标高、寝区及左右舷分配由项目确定。[游戏手册](https://wiki.biligame.com/seer/书籍:赛尔号飞船手册) · [纸本图鉴出处](https://www.bilibili.com/opus/935428415190728737)

## 游戏录像与进服记录

一段于 2025 年 8 月转载的玩家录像中，以下三帧同时有游戏界面与舱名。录制日期和客户端构建号未明。三处是独立的观察点，同版往返路线还有待取得。[玩家录像《赛尔号飞船内部隐藏精灵探索合集》](https://www.233leyuan.com/post-detail/1958152686248176434)

- **05:07，传送舱。** 中央是深蓝凹面及两圈青色地灯，后半周五座倾斜机座朝中央展开，左侧另有精灵中心门。首版建模所用的 2012 资料与该画面分别留档。
- **07:18，资料室。** 地面有圆形 S 纹，后方中央宽台带绿色灯键，两侧翼板内折。活动 UI 遮住了前场，仍须补看进舱落点。
- **07:48，机械室。** 茜茜位于右侧，左后透明立筒有圆点底盘，中央地坪折线两侧有分节青灯。这一帧可用来比较后来版本的工位，画面里的玩家穿着装备。

本轮访问了淘米公开入口，H5 起始文档可达，未能进入服务器或亲历舱间转场。持号者下次可从官方入口补录普通赛尔的后侧与两次完整走停，并按 [#2](https://github.com/lshxzhy/seer-starship-reconstruction/issues/2) 的次序记录每次过门的舱名和落点。[淘米官网](https://seer.61.com/) · [H5 入口](https://h5-seer.61.com/?from=taomee) · [官方操作说明](https://seer.61.com/main/guide/jbcz.html)
