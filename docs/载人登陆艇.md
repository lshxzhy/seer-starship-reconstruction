# L-01 载人登陆艇

L-01 是停靠在赛尔号舷侧的项目原创登陆艇。艇长约 13 米、翼展约 10.8 米。尾门放下后成为坡道，客舱的中央通道一直通到艇首。驾驶席能从前窗看见母舰、行星和地面，台上显示航速、雷达高、飞行阶段和目的地。随身的奥飞滑翔翼仍用于舰内个人通行。[艇体与驾驶舱](../src/galaxy/landing-shuttle.js)

## 第一次驾驶

驾驶台的「航线」「接管」「视角」刻字键可以在三维画面里直接点选。航速、高度、目的地、尾坡和起落架状态来自同一艘艇的当前状态。舷窗按前方、左侧、右侧分组；座椅、仪表和尾门铰节随艇体和坡道运动。驾驶席实拍取自 02 号机位出发、进入驾驶席后尚未离泊的时刻。[驾驶席实景](https://github.com/lshxzhy/seer-starship-reconstruction/releases/download/v0.12.1/shuttle-detail.jpg)

1. 在赛尔号底层传送舱进入编号亮框，按 E。廊车载着小赛尔和 NoNo 下降到轨道层，然后沿舰内导轨驶向该编号的舷侧泊位。
2. 到站后往前走，沿尾坡进入 L-01。继续走到中央驾驶席，按 E。点击「自动飞往草原南坪」即可体验完整的离泊、下降、减速和着陆。用 V 切换艇外视角，拖动画面可以环视。
3. 自己驾驶时点「手动离泊」或「手动起飞」。W/S 前后推进，A/D 或左右方向键转向，上下方向键改变俯仰，Q/R 横移，空格/C 升降，Shift 加力，X 制动。松开推进后，飞控会减速。屏幕方向键和升、降、加力、制动键也可驾驶。
4. 按 M 打开航线。选择自然停放点或赛尔号泊位，可以设为手动航点，也可以让自动驾驶飞往该处。飞行中点「手动接管」可沿当前速度与方向接手。自动巡航使用约 1.5–6.4 倍模拟时间，靠近地面或母舰时降速。
5. 手动着陆时，选平缓、干燥、能放下机翼的地面，减速并降低高度。在低速低空出现「就地着陆」时点选，也可继续缓降到接地。停稳后点「离席下船」，向艇尾步行下坡道。也可以在航线面板里选「离开驾驶席」。
6. 地表点「定位登陆艇」可看到自己与尾坡的方向和距离。返回尾坡按 E，进舱到驾驶席后可选「自动飞往赛尔号泊位」。手动返程时对准原泊位，在对接轴线前减速，出现「锁定对接口」后完成最后的倒车对接。离开驾驶席、走过尾坡，到廊车前按 E 返回出发传送舱。

## 尺度与地形

克洛斯星半径为 48 公里，赤道周长约 302 公里。草原南坪距皮皮活动区约 39 米。经典八处场景沿用原有的步行连接，地心通过藤蔓洞口步行进入。十个已标记着陆点中，蓝脊山鞍部、金河口高岸和绯叶林台距草原约 3.2、4.0、4.9 公里，沿途可观察山脊、河谷及林地高差。这三个外围地点是为飞行补全的地貌。[原作场景图证](克洛斯星图证.md) · [球面地形与停放点](../src/galaxy/klose-surface.js)

母舰位于距克洛斯星地表约 145 公里的驻留位置。模拟采用以星心为原点的米制坐标，记录艇的位置、速度和姿态。自动驾驶根据目标计算推进与制动，加速时间时继续分步计算位移。接近地表时飞控采样地形、植被、坡度和水面，最高航速随净空增加，开阔高空普通推进上限 2.88 公里/秒，加力上限 8 公里/秒。停泊和落地后才能开启尾坡。[动力与自动驾驶](../src/galaxy/shuttle-flight.js) · [母舰泊位与廊车](../src/galaxy/carrier-dock.js)

星际段普通推进与加力的设计上限分别为 98.8、260 公里/秒，实际速度受星体、母舰距离及制动距离影响。X 主动制动比松开推进更快。近地沿球面输送航向，高速跨星时按位移拆分物理步，擦过行星会沿净空球面掠过。进近母舰后按泊位距离限速，对接阶段以低速倒车入坞。

尾坡两侧的固定缸筒与活塞杆随同一铰链展开，喷口内增设导流片。驾驶员走向收窄的驾驶台或尾坡时可以贴着扶边前进。

艇员、仪表和镜头共用艇体姿态。驾驶员下船后，艇留在实际降落点。聊天宿主保存航行状态时，会记录艇的位置、速度、驾驶模式、目标及登船进度；v0.12 的经典区存档按离各星起点的米数换算。外围泊点按地标位置迁移，已停在泊点旁的艇和下船人员保留附近的米制偏移。星际段保留惯性位置、模拟时间和目的地。单文件离线版沿用原有的本地装备存储。
