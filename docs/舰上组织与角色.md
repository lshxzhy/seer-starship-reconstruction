# 舰上组织与角色

舰上通讯采用经典页游设定。名册包含八位有对应舱室的具名角色、一位舰外联络人和一张普通船员角色卡。玩家可以根据自己关心的事找人，比如在机械室找茜茜谈装备，或向肖恩了解 NoNo。具体卡片和来源见[角色名册](../src/ai/characters.json)。

## 舱内近看与角色造型

八人分别占用所在舱室原有的值班名额，地图的舱室说明会显示姓名。走到同舱约四米内，按 E 或点角色即可打开其个人资料。资料卡读取通讯名册的原作记录。本机通讯入口将当前角色 ID 直接交给同名联系人。麦哲伦是舰外联络人。

造型核对了淘米客户端的八张署名角色立绘。罗杰的白盔、金色徽记和蓝领，茜茜的黄盔和紫色提把，派特的透镜与颅顶支架，爱丽丝的粉壳与蓝灯，均分别制作。雷蒙使用灰色机械侧臂，肖恩使用白青冠刺，苏克带双头扳手，克罗使用铜甲与青色面板。立绘没有完整显示的背部结构、工位的米制位置和转身动作由本项目补全。[罗杰](https://seer.61.com/resource/newNpc/oneSide/1.swf) · [茜茜](https://seer.61.com/resource/newNpc/oneSide/2.swf) · [派特](https://seer.61.com/resource/newNpc/oneSide/3.swf) · [爱丽丝](https://seer.61.com/resource/newNpc/oneSide/4.swf) · [雷蒙](https://seer.61.com/resource/newNpc/oneSide/5.swf) · [肖恩](https://seer.61.com/resource/newNpc/oneSide/6.swf) · [苏克](https://seer.61.com/resource/newNpc/oneSide/8.swf) · [克罗](https://seer.61.com/resource/newNpc/oneSide/518.swf)

## 角色卡怎样用于对话

名册的 `schemaVersion` 为 1，`continuity` 为 `classic-webgame`。组织节点用 `id` 和 `parentId` 连接，每张卡的 `departmentId` 指向所属节点。`basis: source` 标记有官网出处的节点，`basis: project-design` 标记本项目的功能分组。官网条目记录于节点的 `sources` 中。

角色卡的 `facts` 存历史事实，`sources` 附出处、日期或资料局限。`persona` 描述项目创作的说话方式，`expertise` 选择适合讨论的主题，`boundaries` 记录尚未确认或超出当前交互的内容。生成的对白是现场角色扮演，引用原作时可以回查对应出处。

`roomId` 指表中工位，`aboard` 表示项目把该联系人列在舰内还是舰外。各工位使用具名实体的稳定 characterId，现场拜访与职务通讯共用同一人。舰内还有一张 `crew` 卡，带 `generic: true`，所属分组为 `general-operations`。它沿用当前人口系统给出的 SE 编号、岗位和所在区域；普通船员之间凭编号区分。其 `facts` 和 `sources` 均为空。12,000 个在舰名额来自本项目扩建方案。

对话可以解释历史任务、介绍舱室和讨论方案。授勋、维修、修改装备等需要真实游戏逻辑支持的操作，应按实际功能说明。使用方法见[项目入口](../README.md)。

## 精灵通讯

运行根目录的「启动舰上通讯.cmd」后，在本地游戏的精灵界面选「交流」。图鉴模式可以与所选物种模拟交流，野外模式对应面前的个体，队伍与仓库中的精灵按持有个体区分会话。精灵通过短动作、叫声和中文意译回应玩家。动作和意译是本项目的演绎。

舰上角色与精灵共用本机 Ollama 的 `qwen3.5:9b`，每次请求关闭思考。启动器会尝试唤起已经安装的本机 Ollama。服务默认监听 `127.0.0.1:8765`，首次生成需要把模型载入内存。下载的独立 HTML 可以离线游玩，通讯面板会提示如何打开本机游戏。服务、模型和会话内容都位于这台电脑上。

服务按图鉴编号从与游戏共用的资料中读取物种名称、属性、可学招式和已登记的等级进化。野外或伙伴会话还可以引用游戏提供的当前等级、体力、招式和地点。精灵通讯返回文本；战斗、治疗、捕捉和道具消耗仍须由玩家在对应游戏界面操作。不同联系人的消息分别保留在当前页面，刷新后清空。[本机通讯服务](../src/ai/server.py) · [通讯界面](../src/ai/dialogue.js)
