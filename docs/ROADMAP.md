# 开发路线

已开放的玩法和操作见[项目首页](../README.md)。本页记录接下来的工作、入口和完成条件。各期可下载成果及影像在[版本记录](https://github.com/lshxzhy/seer-starship-reconstruction/releases)。

## 下一阶段

### 跨场景材质接续

小赛尔的头壳、顶盖和鞋壳使用纯色光滑漆面，舰内近景、行星地表、具名舰员和远处人群共用同一设定。面屏表情及各职业的独立装备沿用各自材质。场景工业件的细微起伏改用切线空间法线，使涂层在舰内缩尺和米制地表有相同的观感。[赛尔机体](../src/population/robot.js) · [工业材质](../src/viewer/lighting.js)

克洛斯星的根拱、菌盖和蕨叶、海洋星护理站与浮台、双子星能源塔和勘察站分别使用植物、矿物、釉面和金属材质。克洛斯星近轨和远处星系视图共用四段环带及其间隙，双星天空的亮边和云影跟随场景光源。[克洛斯星](../src/galaxy/klose-surface.js) · [海洋星](../src/galaxy/ocean-surface.js) · [双星天空](../src/galaxy/twin-panorama.js)

舰壳板缝、舱内甲板和设备盖板共用各自的高度、粗糙度和金属度分布。普通工业件用四种可平铺的微表面区分烤漆、拉丝金属、橡胶和陶瓷。进机械室看防滑面与裸露紧固件，或从 L-01 舱内斜看舷窗，可以对照这些表面的反光。电子脸、标牌和导航灯保留原显示材质。[舰壳](../src/ship/livery.js) · [舱室](../src/habitat/kit.js) · [共用工业材质](../src/viewer/lighting.js)

四颗行星的步行区分别表现干砂、湿缝和矿物切面；海洋星水面使用当地水深和光照。赛尔与 NoNo 的壳、关节、密封圈沿用原配色，精灵的皮毛、羽片、鳍膜等在靠近时有不同的微表面。可在克洛斯草原看皮皮侧身，或到海洋星从岸边走向深水区观察变化。[地貌](../src/galaxy/surface-finish.js) · [海面](../src/galaxy/ocean-surface.js) · [精灵](../src/spirits/partner-figures.js)

拜伦号精灵舱的设备几何由舱室总装继续维护。设备通过原 `byronKit.mat` 创建时即取得材质升级，原来的三个参数仍可用，裸金属和橡胶可传第四个参数 `'metal'` 或 `'rubber'`。开发分支合入后在项目根运行 `python work/assemble-seer.py`，现有预览刷新后读取新的装配结果。[拜伦号材质接口](../src/galaxy/byron-ship.js)

画面继续按地点和可见对象推进。舰体轮廓优先用同一时期的原件定形，逐个补双面结构、装配细部和材质，再与正常游玩视角核对。迪达家族再校形、肩高与关节步态已随统一构建加载，温泉群已显示新体量和造型，同距离肩高及逐项步态仍未确认，用户尚未认可形似；其余形态的转身、停步、展开翼面继续推进。本期已做的舱室与模型在清单中保留。[场景与模型精修](场景与模型精修.md)

1. **完成本轮采集交付与后续选量。** `64199025` 之后的源码已接入克洛斯草原、海洋深水区两处黄晶矿和海洋浅水区一处甲烷，每点每存档采一份；动力室通过背包一次签收全部未售标本，黄晶矿每份 20 豆、甲烷每份 100 豆。三份舰内训练矿样继续独立分批记账。钻头、气体收集器与潜水装由机械室统一配发，这是本项目规则，原作各年代领取条件和刷新机制仍需补证。第一人称水下灯及地表作业入口限制已完成源码修复并随本轮构建加载，灯光与各点采集尚未逐项实操；后续逐种选数量交付尚未接入，不能把现有全量签收写成选量兑换已完成。[本轮接口与状态](HANDOFF.md#2026-11-12-玩家动作与场景作业源码接续) · [采集与背包](背包系统图证.md) · [动力室兑换](动力室物资兑换图证.md)
2. **补齐精灵的历史获得流程。** 优先补四个已建模观察形态的活动进入条件、剧情和实际奖励，再按年代接入其他湿地场次、融合配方与特殊进化。按招式核实高阶效果、魂印、刻印、抗性与特性；联网对战另需回合同步与裁定。队伍、仓库和捕捉沿用已有存档。[精灵系统任务 #13](https://github.com/lshxzhy/seer-starship-reconstruction/issues/13)
3. **补证舰内舱门和角色造型。** 先取得教官办公室至动力室、机械室与资料室的同版双向转场，记录落点、面向、门框与第一个工位。再核对其余舱室的主视图。八名舰员已按各自原版立绘在工位出场。角色补证优先同一代客户端中的工作动作、普通赛尔背面的走停、第一代 NoNo 转身和翼根、奥飞滑翔翼取出及收回；在同一组画面记录日期、来源或时间码。[舰内路线 #2](https://github.com/lshxzhy/seer-starship-reconstruction/issues/2) · [机械室与资料室 #3](https://github.com/lshxzhy/seer-starship-reconstruction/issues/3) · [伙伴图证](超能NoNo图证.md)

## 接续扩建

- **拜伦号。** 用户选定固定撕裂现场，替代上一阶段的分站回放方案。继续比对同期外景、原色图标和登陆甲板画面，有新证据时优先修正背面结构和破口朝向。扩建时保护三处残骸发生点、左舷靠泊净空与逃生舰观察线。[来源与现场](拜伦号与原始黑洞.md)

- **星系。** 双子星九区及跨星门已开放。后续核对悠悠的泉眼出场、荒原野生精灵与两星历史首领的任务条件，再分批接入既有接触、战斗和存档系统。后续行星沿用同一帕诺星图投影与公转时钟。[双子星现有范围](帕诺双子星.md)[两星轨道基准](帕诺轨道与海洋星.md)
- **舰内运输。** 两条升降线已用于载客和矿样配送。扩充物资推车与装卸时，以层门净宽、轿厢尺寸和通道转角安排推入、固定和卸载，再接入物资状态。[升降舱设计](舰内升降系统.md)
- **画面与交互。** 七处地标已按各自年代的画面再校形，重点为召唤场三色站位、禁地共柱岩窗、荣誉大厅分瓣授勋台和发明室悬锥。人员地图和 L-01 航图的操作已分清。后续先取机械室、动力室的同代工作录像，对照矿架取钻、投入资源、兑换后离开的过程修正操作点。召唤场三座的玩法另需同年代的参加条件、消耗和奖励记录。[资料索引](SOURCES.md) · [系统分工](HANDOFF.md)
- **其余研究。** 原版表情菜单、背包及地图连续操作、后来新增的舱室或具名角色，都按时期补来源。空间补全与原作可见构件分别记入所属专题；独立三维角色沿用既有角色 ID。[角色名册](舰上组织与角色.md) · [背包图证](背包系统图证.md)
